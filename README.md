# 🚀 Signal Bot | ربات دستیار و فروشگاهی تلگرام

یک ربات چندمنظوره و پیشرفته تلگرامی که با **Python** و فریم‌ورک **Aiogram 3** توسعه داده شده است.

---

## ✨ امکانات برجسته
- 🛒 **فروشگاه خودکار VPN & V2Ray:** انتخاب حجم، قیمت و صدور فاکتور.
- 💳 **سیستم تایید رسید:** دریافت عکس فیش و پنل تایید/رد ادمین (✅/❌).
- 📥 **دانلودر اختصاصی:** اینستاگرام (پست، ریلز، استوری) و جستجوی موزیک.
- 📢 **قفل کانال (Force Join):** الزام عضویت در کانال‌های اسپانسر.
- ⚡ **معماری ماژولار:** Asynchronous و مدیریت استیت‌ها (FSM).

---

## 📂 ساختار پروژه
```
siganl2bot/
├── main.py              # اجرای اصلی ربات
├── config.py            # تنظیمات متغیرها
├── database.py          # مدیریت SQLite
├── middlewares/         # میدلورهای سیستم
├── handlers/            # مدیریت پیام‌ها
└── .gitignore           # حفظ امنیت اطلاعات حساس
```

---

## 🚀 راهنمای راه‌اندازی
```bash
python3 -m venv venv
source venv/bin/activate
pip install aiogram requests python-dotenv
python3 main.py
```
